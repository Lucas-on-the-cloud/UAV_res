# Notebooks

Kaggle notebooks used for this project. Export from Kaggle (File → Download as `.ipynb`) and place here.

## Planned

- `week1_smoke_test.ipynb` — environment check + YOLOv12-n inference test
- `week2_train_yolov12n.ipynb` — filter VisDrone + train YOLOv12-n baseline
- `week3_train_yolov12s.ipynb` — train YOLOv12-s for size comparison
- `week4_error_analysis.ipynb` — inspect baseline failure modes + ONNX export
- `weekN_synthetic_train.ipynb` — mixed-training experiments

## Convention

- One notebook per major experiment
- Clear naming: `weekN_description.ipynb`
- Save Kaggle "Version" URL in notebook's first cell as a comment for traceability
